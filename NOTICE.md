# Third-party data and fonts

- **OpenNGC** — the deep-sky catalogue subset in `crates/fittle-core/data/targets.json`,
  `targets-extra.json` and `targets-names.json` is derived from OpenNGC by Mattia Verga
  (https://github.com/mattiaverga/OpenNGC), licensed **CC BY-SA 4.0**, via the sibling
  project AstroSideKick. Share-alike applies to these data files only. Some common names
  come from Wikidata (CC0).
- **ESA/Hubble FITS Liberator datasets** are used only as a local, uncommitted test corpus
  (CC BY 4.0, https://esahubble.org/projects/fits_liberator/datasets/).
- **Fonts** embedded for share cards, in `crates/fittle-image/fonts/`: Bricolage Grotesque
  (Mathieu Triay), Inter (Rasmus Andersson) and JetBrains Mono (JetBrains), from
  https://github.com/google/fonts, each under the **SIL Open Font License 1.1** (license
  texts alongside the font files).
