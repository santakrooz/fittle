# Badge

A tinted word or two naming a category or status: an object type, a processing state, a severity.

- The consumer supplies the text and `tone`: `orange` (supernova remnant, broadband), `rose` (emission, Hα), `teal` (OIII, info, Linear), `ok`, `warn`, `bad`, `accent`.
- The tone is 14% as ground with its `*-fg` token as text. Status badges always carry the word; never a colour alone.
