# Segmented

Two to four mutually exclusive modes that change how the current view reads (Linked · Unlinked · Luminance; Grouped · Raw · JSON).

- The consumer supplies `options`, the controlled `value` and `onChange`. Keep labels to one word.
- The selected segment lifts onto `bg-raised` with a `line-strong` ring; it is neutral, not amber, because it is a view setting, not an action.
