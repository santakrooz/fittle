fittle mcp exposes read tools, preview images, and dry-run-first writes. Here Claude inspects a folder, previews a stack, and proposes a header fix.

How much usable data do I have on the Veil, and why does Siril say my focal length is zero?

→ { "subs": 3785, "kept": 3412, "usable_s": 68240, "nights": 6,
    "warnings": ["FOCALLEN missing on 3785", "GAIN 120 on 83 (2026-09-18)"] }
fittle fits_preview
{ "path": ".../r_pp_NGC6995_stacked.fit", "max_edge": 768, "stretch": "auto" }  → image/webp

You have 18 h 57 m of usable 20 s LP subs across six nights (3,412 of 3,785 kept). Sep 22 lost 246 subs to cloud.

Seestar writes FOCALLEN = 0, so Siril can't compute pixel scale. I can set it to 250 mm on all 3,785 subs. Dry run: in-place, no header resize, backups on. Apply it?

fittle fits_set_keywords dry_run
